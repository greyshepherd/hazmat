The replaced build cannot be the one that answered: the idle exit bounds any process to thirty seconds after its last request, and the upgrade takes minutes, so a daemon answering afterwards is executing the bytes at the path launchd registered — `Contents/MacOS/HazmatDaemon` inside the bundle the update replaced

The app's own report of that failure is unchecked: forcing it needs an entry in the feed naming a tampered archive, and publishing one would offer a bad update to every installed copy
